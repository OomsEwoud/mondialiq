CONSTRAINTS:
- ONE script tag per page, total. Do NOT load it conditionally per route
  — that breaks retroactive identity resolution at form-submit time.
- Do NOT load it only on landing pages. Every tracked page builds the
  visitor's journey-history that gets linked when a form is later submitted.
- Do NOT replace `async` with `defer`. Defer waits for HTML parsing and
  delays the first pageview event by hundreds of milliseconds.
- Do NOT self-host or proxy the loader. The provided URL has a
  content-hash cache-buster that updates only when Atbound ships a fix
  — self-hosting silently misses security patches.
- Do NOT wrap in Google Tag Manager. The loader needs first-party cookies
  (`_atb_v`, `_atb_c`) set from the Atbound origin; loading via GTM
  defeats third-party-cookie blocking protections.

SEMANTIC TAGGING FOR SALES INTELLIGENCE:
Keep setup light. Atbound already auto-captures pageviews, engaged time,
sections, clicks, downloads and forms. Your job is only to add a few stable
labels where the code already reveals buying intent, so the lead timeline can

ATTRIBUTE CONTRACT:
- `data-atb-section="Human section name"` on primary page sections. Use names a
  salesperson understands: Hero, Pricing, Services, Cases, Contact.
- `data-atb-cta="machine_intent"` on high-intent CTA links/buttons such as demo,
  quote, contact, pricing, booking and trial actions. Use stable snake_case
  values like `demo_request`, `quote_request`, `contact_sales`.
- `data-atb-label="Human label"` on tracked elements when the visible text is
  vague, dynamic, icon-only, translated elsewhere, or too long. This is the UI
  label shown in Atbound timelines.
- `data-atb-track="category"` + optional `data-atb-label="Human label"` on
  important non-CTA interactions such as project cards, case-study links,
  downloads, mailto/tel/WhatsApp links and product cards.
- `data-atb-skip` on utility UI that should not appear in a sales journey:
  menu toggles, cookie banners, close buttons, search controls, theme toggles,
  carousel arrows and pagination.

CONTENT-SECURITY-POLICY (only if the site sends a CSP header):
Whitelist the loader origin under both `script-src` and `connect-src`
directives. Without `connect-src` the script loads but the POSTs to
/api/track are silently blocked and no events arrive in the dashboard.

COOKIE BANNER (only if this site has one):
Add data-require-consent="1" to the script tag, and call
window.Atbound.grantConsent() from the banner's "accept" handler.
Without consent the loader stays inert (no tracking, no _atb_v cookie).
The loader also auto-honors browser DNT and Sec-GPC — do NOT strip
those checks.
